## 사용자 목표와 확정된 범위

macOS에서 Codex, Claude Code, Antigravity, Hermes가 가능한 한 동일한
사용자 스킬·MCP·이벤트 처리를 사용하도록 한다. 에이전트별 내장 기능·모델·계정까지
동일하게 만드는 작업은 아니다.

- Hermes는 새 `edith`만 고려한다. `iris`, `sophie` 등 기존 프로필은 강의 실습용이며
  비교·동기화 대상에서 제외한다. 기존 프로필을 수정하거나 활성 프로필을 바꾸지 않는다.
- 직접 만든 스킬과 외부 제작 스킬을 구분한다. 직접 제작 확인 스킬은
  `raindrop-devonthink`, `raindrop-zotero`다.
- `dandacompany` 출처는 제외한다. `magma-support`는 강의 실습용이다.
- Matt 스킬은 승인된 폐기·중복 후보 7개와 프로젝트·Claude 전용 4개를 글로벌에서
  제외했다. 최신 원본의 이름 변경·통합을 따라갔고 불필요한 구버전 별칭은 남기지 않았다.
- 선택한 기존 스킬을 갱신하고 필요한 의존성만 추가했다. 신규 스킬 전체 설치를
  승인한 것은 아니다. `research`, `gws-shared`는 설치된 흐름의 의존성으로 추가했다.
- 미설치 항목과 이유도 문서로 남긴다. 원본 파일은 비교·백업 후 반영한다.

## 현재 실제 적용 상태

2026-10-05 인수인계 작성 시 로컬 파일을 다시 확인했다.

| 대상 | 상태 |
| :--- | :--- |
| 공유 경로 | 사용자 스킬 56개. `~/.agents/skills`는 dotfiles의 `.agents/skills`를 참조 |
| Codex·Antigravity | 공유 경로 전체 참조. 시스템·플러그인 기능은 이 숫자와 별개 |
| Claude Code | 공유 스킬 54개 개별 링크. 직접 제작 Raindrop 2개 링크가 아직 없음 |
| Hermes `edith` | 아직 생성하지 않음 |
| 외부 제작 스킬 | 여섯 출처 모두 관리 문서에 고정한 최신 확인 커밋으로 갱신 |
| UA 원본 | 외부 저장소 전체를 fast-forward. `2.9.7`, 작업 트리 깨끗함. 기존 9개 링크 유지 |
| MCP·글로벌 훅 | 이번 스킬 정리 과정에서 변경하지 않음 |

UA와 직접 제작 Raindrop 스킬은 저장소 밖 원본을 링크한다. dotfiles만 복제하면
재현되지 않는다. UA 출처 메타데이터는 설치 기록에 추가했으며 원본 준비가 필요하다.
이번 UA 업데이트는 플러그인 내부 파일을 함께 갱신했지만 에이전트 글로벌 훅 등록을
바꾸거나 개발 의존성 설치·빌드를 수행한 것은 아니다.

## 검증과 남은 불확실성

- 선택한 외부 원본과 설치 파일의 바이트 일치, frontmatter YAML, 설치 기록 JSON,
  폴더 해시, 에이전트 경로 및 깨진 심링크를 확인했다. 무관한 파일·메타데이터·Claude
  링크는 작업 전 백업과 비교하여 보존 여부를 검사했다.
- 문서 상대 링크와 `git diff --check`를 통과했다.
- UA 보조 스크립트 13개 JavaScript / 5개 Python 문법 검사를 통과했다.
- UA 증분 계약·심볼 테스트는 임시 원본에 `vitest`가 없어 실행되지 않았다.
  테스트 성공, 실제 분석 성공, dashboard 동작 확인으로 취급하지 않는다.
- Google의 선택적 helper 링크는 일부 미설치 스킬을 가리킨다. 해당 목록은 관리
  문서에 기록되어 있으며, 필수 `gws-shared`는 설치했다.
- MCP 연결, 계정 인증, 실제 서비스 작업, Hermes 로딩·훅 동작은 아직 검증하지 않았다.

## 다음 작업 순서

1. `git status`와 위 정본을 읽고 현재 상태를 재확인한다. 전체 작업 트리에는
   Aerospace, 셸, 에이전트 설정 등 무관한 변경이 있다. 전체 추가·커밋으로 흡수하지 않는다.
2. 공유 스킬 동기화를 마무리하려면 Claude의 직접 제작 Raindrop 2개 링크와
   각 에이전트의 실제 스킬 선택·로딩을 확인한다. 링크만으로 실행 호환성을 단정하지 않는다.
3. Hermes `edith` 생성 방식과 설정 상속·기본 스킬 중복을 확인한 뒤, 이 프로필만
   공통 경로를 참조하게 한다. 기존 프로필 복제나 활성 프로필 전환을 자동으로 하지 않는다.
4. 전체 계획의 공통 MCP 목록·구현·전송·인증 참조를 확정한다. DEVONthink·Raindrop·
   Zotero는 후보이지 적용 완료 상태가 아니다. Raindrop MCP 저장소 스킬 업데이트와
   MCP 서버 자체 업데이트를 구분한다.
5. 공통 이벤트 의미와 처리 목적을 확정하고 에이전트별 어댑터를 구현·검증한다.
   `Stop`은 작업 목표 달성이 아니라 턴/실행 종료이고, Hermes `on_session_end`도
   매 턴 발생할 수 있다. 지원 차이와 Herdr 관리 파일 소유권은 전체 계획을 따른다.
6. 재현·복구·설정 차이 검사와 실제 실행 증거를 남긴다. 커밋이 요청되면 이번 변경과
   기존 사용자 변경을 구분해 정확한 경로만 검토·추가한다.

이 문서 저장 요청은 남은 설정 작업·MCP 인증·프로필 전환·커밋까지 새로 승인한
것이 아니다. 다음 사용자 요청의 범위에 맞춰 이어간다.

## 환경·복구 주의

- 공유 스킬과 문서는 workspace에서 수정 가능하지만 `~/.claude` 링크 및 외부 UA
  저장소의 쓰기는 권한 승인을 거쳐 수행했다. 다음 세션도 현재 권한을 확인한다.
- 백업 압축·옮겨 둔 제외 스킬·UA 이전 이력 bundle의 위치는 관리 문서의 복구 절을
  참조한다. 임시 폴더이므로 장기 보존되지 않을 수 있다. 복구는 별도 폴더에서 비교한다.
- 직접 제작 스킬 원본인 `sejong-wiki`는 이 작업에서 수정하지 않았다. vault 작업이
  필요하면 Obsidian CLI 규칙을 적용하며 직접 Markdown 편집으로 우회하지 않는다.
- 인증 토큰·계정 파일·대화 기록·세션 DB를 문서나 커밋에 포함하지 않는다.
